# 樱花树搭建方案（便利店后方靠右侧 · 高大茂盛 · 大而对称的树冠）

> 版本：v1
> 更新日期：2026-09-25
> 状态：已实现并验收（2026-09-25）。`node --check` 与 `mkdocs build` 通过；亮/暗全景 + 街角 + 橱窗 + 移动 + 特写截图见 `.documents/阶段截图/樱花树重建-*`。
> 说明：本文件**单独**阐述樱花树的搭建，取代《首页美化-模型上色樱花与电车设计方案.md》§9 / §10 里旧树（落在店侧 (3.32, −1.60)、冠整体偏 −x）的实现口径——旧树代码已删除，本文件是樱花树唯一的事实来源。

## 0. 一句话结论

在便利店**后方靠右侧**长一棵**高大茂盛**的樱花树：树干细、枝少，视觉重心全在**大而对称**的树冠上，树冠从上方罩住店顶右段，形成「树从店后探出、冠遮蔽店顶」的读感。

## 1. 落位（便利店后方靠右侧）

- 便利店体块：`STORE = { x0: −1, x1: 3, z0: −2.6, z1: 0.6, h: 2.6, wall: 0.12 }`，屋顶顶面 y = 2.76。
- 树干落点：**(2.0, −2.85)**。z = −2.85 在店后墙 `z0 = −2.6` 再往后 0.25 m（避开墙厚 0.12 + 描边余量）；x = 2.0 落在店体右半侧（店宽 x ∈ [−1, 3]）。
- 为什么不是 x = 3.3：底座半宽只有 3.6，若把树干贴在店右缘（x ≈ 3.3），一颗「左右对称」的大冠会在 x ≤ 3.6 内**无法向右展开**，只能整体左偏——这正是旧树「花只长在一边」的几何根因。x = 2.0 让冠左右各留约 1.5 m，放得下一颗对称大冠。

## 2. 体量（高大茂盛，冠大于枝）

| 项 | 值 | 说明 |
|---|---|---|
| 干高 | 3.6 m | 约店高 2.6 的 1.4 倍；冠顶 4.75 m 约店高的 1.8 倍 |
| 干底 / 顶半径 | 0.14 / 0.07 | 下粗上细，细干不抢镜 |
| 树冠椭球 | 中心 (2.0, 3.85, −2.5)，半径 rx = 1.0 / ry = 0.9 / rz = 0.55 | 冠宽 / 冠高 / 冠深分别由 rx / ry / rz 控制 |
| 花球 | 26 颗，基础半径 0.55，缩放 0.82–1.15 | 单个 `InstancedMesh`，不增 draw call；实际半径 0.45–0.63 |
| 枝 | 3 根短枝（r 0.040–0.045） | 只做「干 → 冠」结构过渡，重点不在枝 |

树冠覆盖范围（实测 AABB）：

| 轴 | 范围 | 对照 |
|---|---|---|
| x | [0.45, 3.55] | 贴底座右缘 3.6，不越界；罩住店顶 x ∈ [0.45, 3.0] |
| y | [3.01, 4.75] | 冠底 3.01 > 店顶 2.76，净空 0.25 m |
| z | [−3.60, −1.40] | 贴底座后缘 −3.6；前伸到 −1.4，罩住店顶 z ∈ [−2.6, −1.4] |

即树冠罩住店顶的**右后段**（约店宽右 64% × 店深后 38%），从全景机位读作「树从店后探出、冠遮店顶」。

## 3. 树冠为什么「大而对称」（针对「只有半棵树」）

旧树的失败点：冠心 (2.35, 3.85, −1.7) 相对树干 (3.32, −1.60) 偏 −x 约 0.97 m——花全在左，右侧只剩枝。本轮换一种做法：

1. **对称铺球**：以树干正上方为冠心，把 26 颗花球按「1 中心 + 3 层环形 × 8 向 + 1 顶」绕 y 轴 8 向均匀铺出，左右（x）与前后（z）天然对称，任何机位都不「一边重」。
2. **冠远大于枝**：花球半径 0.45–0.63，树干直径 0.28，3 根短枝全部埋在冠内，视觉重心完全在冠上。
3. **只在 z 向前移 0.35 m 做「向前探出罩店」**（冠心 z = −2.5 vs 干 z = −2.85），不在 x 上偏移——保留左右对称，同时保留「遮蔽」关系。

## 4. 穿模问题（四处，全部避免）

| 冲突 | 处置 | 验收 |
|---|---|---|
| 冠底 vs 店顶（y = 2.76） | 冠最低花球底 y = 3.01，净空 0.25 m | 逐球做 sphere-box 最近距离，全部 > 半径（实测穿模数 0） |
| 树干 vs 店后墙（z = −2.6） | 干 z = −2.85、底半径 0.14 → 干前端 −2.71，离墙 0.11 m | 不相交 |
| 树池 / 落瓣 / 地灯 vs 店体 | 全部落在 z < −2.6 的店后带；落瓣半径 0.2（最远 z = −2.65） | 不越入店体 |
| 冠越出底座（±3.6） | 冠 x ∈ [0.45, 3.55]、z ∈ [−3.60, −1.40] | 逐球 `|center| + r ≤ 3.6`，实测越界数 0 |

## 5. 实现方案（代码）

### 5.1 单一事实来源 `SAKURA`（`scene-builder.mjs`）

```js
export const SAKURA = {
  x: 2.0,            // 树干 x：便利店右半侧后方
  z: -2.85,          // 树干 z：店后墙 z0=-2.6 再往后 0.25m
  trunkHeight: 3.6,  // 干高（干顶伸进树冠中心花球）
  trunkRadius: 0.14, // 干底半径（顶半径取一半）
  blobR: 0.55,       // 花球基础半径（实际半径 = blobR × scale）
  crown: { x: 2.0, y: 3.85, z: -2.5, rx: 1.0, ry: 0.9, rz: 0.55 }, // 树冠椭球
  canopy: [2.0, 3.85, -2.5] // 花瓣发射盒中心 = 树冠中心
};
```

### 5.2 花球生成（对称铺球）

```js
const blobs = [];
blobs.push([C.x, C.y, C.z, 1.15]);                 // 中心（包住干顶）
[
  { fy: -0.35, k: 0.90, s: 0.95 },                 // 下环
  { fy: 0.00, k: 1.00, s: 1.00 },                 // 中环
  { fy: 0.32, k: 0.78, s: 0.90 }                  // 上环
].forEach(function (ring) {
  for (let i = 0; i < 8; i++) {                    // 8 向对称
    const a = (i / 8) * Math.PI * 2;
    blobs.push([
      C.x + Math.cos(a) * C.rx * ring.k,
      C.y + ring.fy * C.ry,
      C.z + Math.sin(a) * C.rz * ring.k,
      ring.s
    ]);
  }
});
blobs.push([C.x, C.y + 0.50 * C.ry, C.z, 0.82]);  // 冠顶
// 全部 26 颗 → 1 个 IcosahedronGeometry(blobR, 1) 的 InstancedMesh
```

### 5.3 树干 / 短枝 / 树池 / 落瓣 / 地灯

- **树干**：`CylinderGeometry(trunkRadius*0.5, trunkRadius, trunkHeight, 8)`，干顶直接伸进中心花球（覆盖余量 +0.364 m），不露秃头。
- **3 根短枝**：基部在 `y = trunkHeight − 0.25`，端点由下环前向三颗花球（45° / 90° / 135°）中心反推到 0.55 r 处——保证枝端埋在花球内；只做结构过渡，不追求枝量。
- **树池**：`TorusGeometry(0.2, 0.035)` 环（外径 0.235）+ 泥土片，落在 (2.0, −2.85)；外径受「不越过店后墙 z=−2.6」约束（0.2 + 0.035 = 0.235 ≤ 0.25）。
- **静止落瓣**：7 片贴花，半径 0.2 环绕干周（最远 z = −2.65，不越入店体）。
- **地灯**：0.07×0.14×0.07 emissive 小方块，落在 (2.38, −2.75)。

### 5.4 花瓣与灯光随动

- `rain-system.mjs` 的 `createPetalSystem`：默认 center `(2.0, 3.85, −2.5)`、半盒 `(1.55, 0.85, 1.1)`——对齐冠 AABB，花瓣从冠内、而非冠外凭空出现；风向保持 −x，从店后右方吹过店顶。
- `LIGHT_ANCHORS.sakura = [2.0, 3.0, −2.2]`：夜景点光放在冠前下方，照亮冠底与店顶后段。
